
# 🏦 Loan Approval Prediction (ML Project)

## 📌 Description
This is an end-to-end machine learning project that predicts whether a loan will be approved or not based on applicant details.

---

## 🎯 Problem Statement
Financial institutions need to decide whether a loan should be approved based on various applicant features. This project helps automate that decision using machine learning.

---

## 📊 Dataset
- Contains applicant details like:
  - Gender
  - Income
  - Loan Amount
  - Credit History
  - Property Area
- Target variable: Loan Status (Approved / Not Approved)

---

## 🛠️ Tech Stack
- Python 🐍
- Pandas & NumPy
- Scikit-learn
- Matplotlib / Seaborn
